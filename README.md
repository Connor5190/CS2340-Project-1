# Atlanta Food Finder

A Django-based web application for discovering and managing your favorite restaurants in the Atlanta area. The application integrates with Google Maps API to provide interactive maps, restaurant search functionality, and a personalized favorites system.

## Features

- **User Authentication**: Secure signup and login system for personalized experiences
- **Interactive Map**: Browse restaurants on an interactive Google Maps interface with custom markers
- **Search & Filters**: Search restaurants by name, filter by ratings, and adjust distance radius
- **Restaurant Details**: View detailed information including ratings, hours, cuisine type, address, and websites
- **Favorites System**: Save your favorite restaurants to a personal profile
- **User Profile**: Access your saved favorites and navigate between different sections
- **Database Integration**: Stores restaurant data locally using SQLite

## Technology Stack

- **Backend**: Django 5.1.1
- **Database**: SQLite3
- **APIs**: Google Maps API, Google Places API
- **Frontend**: HTML5, CSS3, JavaScript
- **Authentication**: Django's built-in authentication system
